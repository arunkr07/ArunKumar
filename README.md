### 2. Multi-Database Query Engine SDK

**Python · Pydantic · SQLite · PostgreSQL · MySQL · MongoDB · Redis · Pytest**

A Python SDK for AI-powered database querying that translates natural-language questions into structured database operations across multiple database systems.

**Key implementation details**
- Supports SQLite, PostgreSQL, MySQL, MongoDB, and Redis.
- Integrates OpenAI-powered query planning.
- Provides configurable database connections, timeouts, result limits, and retry settings.
